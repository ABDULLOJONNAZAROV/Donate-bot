# Изменения в подготовленной сборке

## Улучшения безопасности и надёжности

- `DEV_MODE` теперь включается только явным значением `1`, `true` или `yes`; значение `0` больше не включает обход проверки Telegram WebApp.
- Проверка `initData` дополнена проверкой формата подписи, `auth_date` (не старше 24 часов, допустимое отклонение будущего времени — 60 секунд) и корректного положительного Telegram user ID.
- Проверка баланса и списание в Mini App-заказе выполняются под одной пользовательской блокировкой, чтобы параллельные запросы не могли потратить один и тот же остаток.
- Цена заказа берётся из серверного каталога; клиентская цена не используется как запасной источник. Добавлена проверка цены и идентификатора получателя.
- Кредит настройки чувствительности начисляется только при статусе заказа `done`, в соответствии с комментарием в исходном коде.
- CORS больше не разрешает credentialed-запросы при wildcard origin.
